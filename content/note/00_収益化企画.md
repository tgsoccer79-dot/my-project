# note 収益化 企画書（ふるさと納税）

> 既存の知識ベース（docs/）とダッシュボードの分析力を、noteコンテンツに変換する戦略。

## 差別化の核

| 持っているもの | 競合との差 |
|---|---|
| 最新制度知識（告示第220号まで） | 多くの記事は2025年で止まっている |
| 総務省データ分析基盤 | データ可視化込みで語れる |
| **内部ビッグデータ（500自治体・返礼品/ポータル詳細）** | ★最大の武器。一般入手不可 |
| 自治体への業務委託実績 | 現場感のある実務解説ができる |

→ **「データに基づく一次解説」**がポジショニング。憶測記事との明確な差。

## コンテンツ階層（無料→有料の導線）

### 第1層：無料記事（信頼構築・集客）
1. **【2026年完全版】制度改正まとめ** ← 作成済み（01_2026制度改正まとめ_無料.md）
2. ポイント禁止の「その後」レポート（市場二極化）
3. 2025年返礼品トレンド（米3倍・日用品台頭）

→ SEO・拡散狙い。docs/ がそのまま素材になる。

### 第2層：有料単品記事（500〜1,000円）
- **自治体担当者向け：経費率を5割以内に収める実務**
- **返礼品カテゴリ別の伸び率データ＋解説**（内部データの匿名化集計）
- **ポータル選定の意思決定フレーム**

### 第3層：月額マガジン（800〜1,500円/月）
- 制度改正の速報解説（ニュース自動更新の仕組みが供給源）
- 月次の市場データ更新
- 購読者限定のデータCSV

### 第4層：データ商品（単品 2,000〜5,000円）
- 全自治体経費率ランキングCSV＋解説PDF
- 都道府県別・カテゴリ別の分析パッケージ

## ターゲット別の刺さり方

| ターゲット | 刺さるコンテンツ | 価格許容度 |
|---|---|---|
| 自治体職員 | 実務・コンプラ・他自治体比較 | 高（業務予算） |
| 返礼品事業者 | カテゴリ伸び率・ポータル戦略 | 中〜高 |
| 一般寄附者 | 制度改正・お得情報 | 低（無料で集客） |
| メディア・ライター | データ引用元 | — |

→ **自治体職員と事業者がマネタイズの主戦場**。一般寄附者向けは集客用。

---

## 注意点（重要）

- **内部データは必ず匿名化・集計化**してから使う。個社特定可能な形は厳禁
- 業務委託先との守秘義務契約（NDA）を確認。生データの公開は不可
- 「総務省公開データ由来」と「内部データ由来」を記事内で明示し、信頼性を担保
- 制度解説は一次情報（告示・大綱）の出典を必ず添える
