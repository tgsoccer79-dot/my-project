# note 収益化 企画書（ふるさと納税）

> **方針：総務省の公開データのみを使用。内部データは一切使わない。**
> 収益源は ①note（有料記事・サポート）＋ ②楽天アフィリエイト の2本立て。

## 収益モデルの全体像

```
[note記事：制度解説・市場分析（総務省データ）]
        ↓ 信頼・集客
   読者が「で、何を選べばいい？」と思う
        ↓
[記事末尾：楽天ふるさと納税アフィリエイトリンク]
        ↓
   読者が寄附 → アフィリエイト報酬
        +
[有料note・サポート機能] → note収益
```

**ポイント：制度解説で信頼を作り、楽天リンクで刈り取る。**
データ分析記事は「この人は詳しい」を証明する装置。最後に具体的な返礼品へ誘導する。

## 差別化の核（総務省データのみで戦う）

| 持っているもの | 競合との差 |
|---|---|
| 最新制度知識（告示第220号・6割ルール・193万円上限まで） | 多くの記事は2025年で止まっている |
| 総務省データの可視化・分析力 | 数字とグラフで語れる（憶測記事と差別化） |
| 自治体業務委託の現場感 | 制度の「実務的な意味」を説明できる |

→ 内部データがなくても、**「一次情報＋正確な分析」**で十分に勝てる。
むしろ公開データのみなのでNDAリスクゼロ・引用自由で気楽に書ける。

## 楽天アフィリエイトの設計

### 仕組み
- 楽天アフィリエイト（無料登録）→ 楽天ふるさと納税の商品リンクを生成
- 報酬率はふるさと納税で概ね1〜2%程度（時期・カテゴリで変動）
- 寄附額1万円なら100〜200円。**記事のPV×誘導率がそのまま効く**

### 記事への自然な組み込み方
1. 制度・市場の解説で価値提供（ここが本体）
2. 「2025年の人気返礼品ランキング」など**データに基づく紹介**
3. 各返礼品に楽天ふるさと納税リンク
4. 「※本記事はアフィリエイトリンクを含みます」を明記（必須）

### 相性の良い記事テーマ
- 「2025年 楽天ふるさと納税ランキングTOP10を解説」← henreihin_ranking.csv が素材
- 「米が人気No.1の理由（データで見る）」← 米カテゴリ → 米の返礼品リンク
- 「1万円台で選ぶコスパ最強返礼品」← 価格帯データ → リンク
- 「ホタテ・牛タン・シャインマスカット 2025年の勝者」← トレンド → リンク

## コンテンツ階層

### 第1層：集客記事（無料・SEO・楽天リンク付き）
1. **【2026年完全版】制度改正まとめ** ← 作成済み
2. **2025年 人気返礼品ランキング解説**（楽天リンク主体）← 収益の主力
3. **ポイント禁止の「その後」**（市場二極化の解説）
4. **1万円台コスパ返礼品**（楽天リンク主体）

### 第2層：有料note（500〜1,000円）
- 「控除上限額の正しい計算と、損しない寄附の順番」
- 「2026年改正で“買い時”が変わる返礼品カテゴリ」
- データ解説を深掘りしつつ、結論で楽天へ誘導

### 第3層：noteサポート / メンバーシップ
- 制度改正の速報解説（ニュース自動更新が供給源）
- 月次の市場トレンド更新

## ターゲット

| ターゲット | 刺さる記事 | 収益経路 |
|---|---|---|
| 一般寄附者（メイン） | ランキング・コスパ・制度のお得情報 | 楽天アフィリ |
| ふるさと納税初心者 | 仕組み・控除計算・始め方 | 楽天アフィリ＋有料note |
| 情報感度の高い層 | 制度改正の深掘り・データ分析 | 有料note・サポート |

→ **一般寄附者の数を集める**のが楽天アフィリの基本。PV勝負。

## 注意点

- **アフィリエイトリンクを含む旨を必ず明記**（景品表示法・ステマ規制対応／2023年10月〜ステマ規制施行）
- 返礼品の在庫・価格は変動するため「2025年時点」と明記
- 制度解説は一次情報（告示・大綱）の出典を添える
- 楽天アフィリエイトの規約（リンクの貼り方・禁止事項）を確認
