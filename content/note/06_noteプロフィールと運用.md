# note プロフィール文 ＆ 運用ガイド

## プロフィール文（コピペ用）

### パターンA：専門性前面（信頼重視）

```
ふるさと納税を「データ」で解説します。

自治体のふるさと納税業務を支援する仕事をしており、総務省の公開データ
（現況調査）を日常的に分析しています。

ネットに溢れる「なんとなくおすすめ」ではなく、実際の人気ランキングや
市場データという一次情報をもとに、本当に役立つ情報だけをお届けします。

▼こんな人に
・どの返礼品を選べばいいか迷っている
・制度改正（2026年の6割ルール等）が気になる
・データで納得して寄附したい

制度解説・返礼品ランキング・控除のしくみまで、わかりやすく書いていきます。
スキ・フォローで応援いただけると嬉しいです。
```

### パターンB：親しみ重視（一般寄附者向け）

```
ふるさと納税、得したいけど難しそう…という人の味方です🍙

自治体のふるさと納税支援が本業。総務省データを分析しているので、
「今、本当に人気の返礼品」「損しない選び方」をデータ付きで解説します。

米・牛タン・ホタテ…2025年の勢力図はかなり変わりました。
最新ランキングと制度のしくみ、やさしくお伝えします。

迷ったときの参考にどうぞ。フォローで最新情報をお届けします😊
```

→ **集客（楽天アフィリ）狙いならパターンB、有料note・専門性狙いならパターンA**。
最初はBで間口を広げ、ファンがついたらAの専門記事も出す二段構えが有効。

## 投稿のコツ

- **タイトルに【2025年】【データで解説】など具体性**を入れる（クリック率↑）
- **見出しを多めに**（noteは流し読みされる）
- **季節を意識**：ふるさと納税は10〜12月が最需要。秋に記事を厚くする
- **ハッシュタグ**：#ふるさと納税 #節約 #返礼品 を付ける
- **記事末尾の相互リンク**で回遊させる（既に各記事に設置済み）
