# note プロフィール ＆ 運用ガイド

> **アカウント名：ふるさと納税をお得に最大限活用する人**
> 方針：トーンは「専門性×親しみ」のバランス。肩書きは**データ分析・ダッシュボード運営**を軸にする
> （自治体支援などの実務肩書きは出さない）。

---

## 1. アカウント名

```
ふるさと納税をお得に最大限活用する人
```

- 読者のベネフィット（お得・最大限）がそのまま名前になっている＝刺さる
- 「ふるさと納税」が頭にあり検索でヒットしやすい
- X（旧Twitter）・マガジン名にもそのまま転用可

## 2. プロフィール欄（短文・コピペ用）

noteのプロフィール欄は短く表示されるため、**1〜2文で「何者か」が伝わる**のが理想。

### 採用案（メイン）

```
ふるさと納税を“お得に最大限”活用する人📊

総務省の公開データを分析するダッシュボードを自作・運営しています。
人気返礼品ランキングや制度改正を、数字の裏付け付きでわかりやすく。
損しない・取りこぼさない選び方を、いっしょに見ていきましょう🍙
```

### 短縮版（文字数を詰めたいとき）

```
ふるさと納税をお得に最大限活用する人📊｜総務省データ分析ダッシュボードを自作運営
｜人気返礼品ランキング・制度改正・損しない選び方をわかりやすく
```

### キーフレーズ（プロフィール・ヘッダー画像に使える）
- 「ふるさと納税を、お得に。最大限に。」
- 「データで選ぶ、いちばん得するふるさと納税。」
- 「なんとなく選んで、損していませんか？」

## 3. 固定の自己紹介記事（プロフィール記事・コピペ用）

noteは1記事を「固定表示」できる。初訪問者がフォローを決める判断材料になるので、これを置く。

```markdown
# はじめまして｜「ふるさと納税をお得に最大限活用する人」です

ご訪問ありがとうございます。
「ふるさと納税をお得に最大限活用する人」として、この制度を**データの裏付け付き**で解説しています。

せっかくのふるさと納税、なんとなく選んで損したり、枠を取りこぼしたり——
そんなもったいない状況をなくすのが、このアカウントの目的です。

## なぜ「データ」なのか

ふるさと納税の情報は、ネット上に山ほどあります。
でも、その多くは「なんとなくおすすめ」「個人の感想」止まり。

「本当に人気なのはどの返礼品？」
「制度改正で、結局なにが変わるの？」
「自分はいくらまで寄附していいの？」

——こうした疑問に、**総務省の公開データ**という一次情報で答えたい。
そう思ってこのアカウントを始めました。

## やっていること

私は、総務省が毎年公表する「ふるさと納税に関する現況調査」のデータを
分析するダッシュボードを自作・運営しています。

- 全国1,700超の自治体の寄附額・経費データ
- 各ポータルの人気返礼品ランキング
- 制度改正（2026年の6割ルール等）の最新情報

これらを、**専門用語をかみくだいて**お届けします。

## こんな人に読んでほしい

- どの返礼品を選べばいいか迷っている人
- 制度のしくみを正しく理解したい人
- データで納得して寄附したい人

## 主な記事

- 【2026年完全版】ふるさと納税の制度改正まとめ
- 【2025年最新】人気返礼品ランキングをデータで解説
- ふるさと納税の控除上限と「損しない寄附の順番」

役に立ったらスキ・フォローで応援いただけると嬉しいです。
最新情報を更新していきます🍙

※一部記事はアフィリエイトリンクを含みます。
```

## 4. プロフィール画像・ヘッダーの方針

- **アイコン**：データ感のあるシンプルなもの（グラフ・📊・🍙の組み合わせ等）。顔出し不要
- **ヘッダー画像**：キーフレーズ＋シンプルなグラフモチーフ。Canva等で無料作成可
- 統一感が「ちゃんとした発信者」の印象をつくる

---

## 5. 記事公開の順番

基礎から着実に積み上げる方針。初心者の入口記事を土台に置く。

| 順番 | 記事 | 狙い |
|---|---|---|
| 0 | 自己紹介記事（固定） | フォロー判断材料 |
| 1 | **ふるさと納税とは？入門ガイド（07）** | 基礎・SEOの土台・全記事の入口 |
| 2 | 控除上限と寄附の順番（05） | 初心者の不安解消 |
| 3 | 人気返礼品ランキング（02） | 楽天アフィリの主力 |
| 4 | 1万円台コスパ返礼品（04） | 楽天アフィリ |
| 5 | 制度改正まとめ（01） | 専門性の証明・差別化 |

→ 入門ガイド（07）を最初に置くと、後続の記事すべてに「次に読む」で送客でき、回遊が生まれる。
→ 自己紹介＋入門ガイド＋もう1本を同時公開すると、訪問者がフォローしやすい。

## 6. 投稿のコツ

- **タイトルに【2025年】【データで解説】など具体性**を入れる（クリック率↑）
- **見出しを多めに**（noteは流し読みされる）
- **季節を意識**：ふるさと納税は10〜12月が最需要。秋に記事を厚くする
- **ハッシュタグ**：#ふるさと納税 #節約 #返礼品 を付ける
- **記事末尾の相互リンク**で回遊させる（各記事に設置済み）
